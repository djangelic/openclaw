## Usage Guidelines
- Use the SVG logo for web interfaces
- Use the ASCII art for CLI tools and terminal output  
- Use the badge for documentation and README files
- Maintain the blue crystal + gold claw color scheme
- The diamond emoji 💎 can be used as a simple icon reference

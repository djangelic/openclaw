## Contributing Images

When adding screenshots:
1. Use high-resolution images (at least 1200px wide)
2. Ensure UI elements are clearly visible
3. Include browser/application chrome for context
4. Use consistent themes/styling across screenshots
5. Name files descriptively with lowercase and hyphens

## Image Guidelines

- **Format**: PNG for screenshots, JPG for photos
- **Size**: Optimize for web (compress but keep readable)
- **Alt text**: Ensure README includes descriptive alt text
- **Privacy**: Remove any personal information from screenshots
